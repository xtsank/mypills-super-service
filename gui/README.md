# MyPills GUI

Интерфейс MyPills на React + TypeScript для API v2. Экраны входа и регистрации,
профиля, нескольких аптечек с позициями, рекомендаций и списка пополнения
доступны пользователю; редактирование каталога лекарств доступно администратору.
Логика экранов находится в `src/viewmodels`, запросы и типы API — в `src/api`,
состояние сессии — в `src/store`, представление — в `src/views`.

## Быстрый старт

```bash
npm install
npm run dev
```

## Переменные окружения

- `VITE_API_BASE_URL` — базовый URL API (например, `http://localhost:8080`).

## Скрипты

- `npm run dev` — дев-сервер Vite.
- `npm run build` — сборка.
- `npm run preview` — предпросмотр сборки.
