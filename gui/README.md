# MyPills GUI

Интерфейс MyPills на React + TypeScript для API v2. Экраны входа и регистрации,
профиля, нескольких аптечек с позициями, рекомендаций и списка пополнения
доступны пользователю; редактирование каталога лекарств доступно администратору.
Логика экранов находится в `src/viewmodels`, запросы и типы API — в `src/api`,
состояние сессии — в `src/store`, представление — в `src/views`.

## Запуск через Docker Compose

Из корня проекта запусти `docker compose up -d --build` и открой
`http://127.0.0.1:8088/legacy/`. Контейнер GUI отдаёт собранные файлы через
внутренний Nginx, а браузер отправляет запросы на `/api/v2/` по тому же адресу.

## Запуск Vite для разработки

```bash
npm install
npm run dev
```

Открой `http://localhost:5173/legacy/`. Vite передаёт запросы `/api/` в
запущенный стенд на `127.0.0.1:8088`.

## Переменные окружения

- `VITE_API_BASE_URL` — необязательный адрес API для отдельного запуска Vite
  (например, `http://127.0.0.1:8080` для Go-сервера вне Docker).

## Скрипты

- `npm run dev` — дев-сервер Vite.
- `npm run build` — сборка.
- `npm run preview` — предпросмотр сборки.
